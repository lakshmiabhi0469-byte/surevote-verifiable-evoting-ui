WE ARE HERE TO HELP

Help & support

Common questions about using the SureVote demonstration portal.

Can I change my selection after submitting?

In this demo, the ballot is marked as submitted after confirmation. Reset the browser's site data to restart the demonstration.

Is my vote connected to a real election?

No. This is a front-end academic project using sample candidate and voter information. It does not send votes to a server.

What is the receipt reference used for?

It is a sample reference generated in your browser session. You can use it on the Verify Vote page to demonstrate a basic lookup flow.

Who can I contact for project questions?

For a classroom demonstration, contact your project guide or the faculty member supervising the project.
