## 1. About the Project

SureVote is a web-based electronic voting project designed to demonstrate a digital voting interface and explore the concept of verifiable electronic voting.

The project aims to provide an accessible and user-friendly interface for understanding how an electronic voting workflow can be presented digitally.

## 2. Objectives

- Explore the concept of electronic voting.
- Develop a simple and user-friendly voting interface.
- Understand the role of web technologies in digital voting systems.
- Explore transparency and verifiability in electronic voting.
- Provide a platform for demonstrating the project workflow.
